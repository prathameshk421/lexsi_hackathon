Frugal Analyst: a 3.35B model that answers database questions with few, verified tool calls

Ask a small model a business question about a database and it usually does one of two things. It runs the same broken query again and again, or it skips the database and makes up a number. We wanted it to act like a careful analyst. Look at the schema, write one good query, and report what came back.

We fine-tuned Tiny Aya Global (3.35B, LoRA) to answer analytics questions over SQLite with two tools, get_schema and run_sql. The reward pays for a correct answer first. Then it pays for a cheap path: fewer tool calls, fewer rows and less database work. A plain answer-match reward is easy to fool, so ours checks the evidence. An answer counts only if a real query on a real table returned it. Typing the answer into the SQL does not count.

We built 5 synthetic SQLite databases with 48 question templates. One whole domain (saas) never appears in training, so it tests how well the model handles a new database. We also held 12 question templates out of the SFT data, so that RL had something new to learn.

The pipeline uses both required toolkits. AgentTune runs LoRA SFT on scripted expert trajectories, then GRPO with real tool calls (50 steps, then 150 more). AuditKit scores every model from saved traces, including tool-call accuracy. Confidence intervals come from a paired bootstrap over tasks.

On the held-out domain, task success goes from 8% for the base model to 46% after SFT and 50% after GRPO. Answers come back twice as fast (11.6 s to 5.8 s), and tool-call F1 rises from 0.68 to 0.93. On the seen domains, success goes from 8% to 88%.

GRPO clearly cut tool calls on both test sets. It lifted the question types that only RL trained on from 45% to 79%. In a second test, we gave the teacher a wasteful habit on purpose. GRPO removed part of it, with no clear change in accuracy.

An offline audit shows the evidence check works. Nine scripted ways to cheat earn half the reward without it and almost nothing with it.

On Hugging Face we release seven LoRA adapters, the tasks, every evaluation trace, the GRPO rollouts and the training logs. The GitHub repo has the full code and a demo app that replays runs side by side. It also has the steps to reproduce every number.
